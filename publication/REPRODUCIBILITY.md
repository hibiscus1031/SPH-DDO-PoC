# Publication reproducibility

## Figures

All six main figures are generated by `08_scripts/publication_p3_figures.py`. The script reads frozen ledgers and metric files listed in `publication/p3_visual_qa_report.md` and writes `figures/main/figure01` through `figure06` in SVG, PDF, PNG, and 600 dpi TIFF formats. The visual QA report records that no manual raster edit, external graphics editor, scientific recomputation, or post-hoc value adjustment was used.

The panel-to-claim mapping is `publication/p3_figure_panel_claim_map.csv`; the earlier plan-level mapping is `publication/figure_to_claim_map.csv`. Existing source hashes and authorized display transformations are recorded in `publication/p3_visual_qa_report.md`.

Because the frozen numerical inputs under `data/` are intentionally external to ordinary Git, a fresh clone alone cannot rebuild the figures. With the matching external data tree and a compatible Python environment, generation is scripted. Current status: **PARTIAL**.

## Tables

The main table content is recorded in `publication/p3_main_tables.md`. Row-level evidence and claim boundaries are mapped in `publication/p3_table_claim_map.csv`; the earlier source-plan mapping is `publication/table_to_claim_map.csv`. `08_scripts/publication_p1_assemble.py` generates the plan-level mapping, while the final Markdown table assembly is not represented by one verified end-to-end command. Current status: **MANUAL_OR_PARTIALLY_REPRODUCIBLE**.

## Inputs, outputs, and prohibited actions

- Inputs: frozen reports, CSV/JSON metric ledgers, manifest hashes, and the external `data/` tree.
- Figure script: `08_scripts/publication_p3_figures.py`.
- Figure outputs: `figures/main/`.
- Table evidence: `publication/p3_table_claim_map.csv` and its referenced artifacts.
- Claim audit: `publication/p3_claim_audit.md` and `publication/claim_ledger.csv`.

Do not regenerate the atlas, change frozen metric files, create neural training, or reinterpret display timestamps as experiment timestamps during publication rebuilds.
