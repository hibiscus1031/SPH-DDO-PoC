# Imported baseline boundary

This directory contains a byte-identical, dependency-closed subset of the historical project-owned Stage 01C static SPH implementation. Import does not transfer ownership of historical conclusions or upgrade their status.

Included functionality:

- deterministic two-dimensional periodic neighborhoods and structural audits;
- two-dimensional Wendland C4 values and gradients;
- raw/normalized/corrected interpolation and differential-operator candidates;
- reciprocal conservative pressure pair forces;
- reciprocal conservative physical-viscosity pair forces and diagnostics.

Excluded functionality includes integrators, dynamic solvers, rollouts, Taylor–Green fixtures, learning code, optimizers, high-resolution SPH references, historical sealed tests, and all LCDF artifacts.

The inherited claim boundary is static and formula-specific. Stage 01C operator evidence passed within its frozen matrix, but the historical full Stage01 V2 qualification was not restored and remained `V2_QUALIFICATION_FAIL`. See the inherited-artifact manifest for exact paths and hashes.
